# 《项目说明书》问题回复

> 使用方式：请直接在每个问题下方填写你的回复；不确定的地方可以写“待定”“倾向于……”或给多个备选方向。

## 1. 产品定位

### 1.1 这个游戏最核心的体验是什么？
可选参考：
- 偏《DNF》：刷图、掉装、强化、毕业追求
- 偏《元气骑士前传》：轻松战斗、职业技能、爽快清怪
- 偏肉鸽：每局随机 Build、死亡重开、局内成长强
- 三者混合，但装备刷宝是第一核心

你的回复：
- 三者混合，但装备刷宝是第一核心。装备可以组合出技能的裂变结果，类似于《暗黑破坏神》的流派体验。


### 1.2 你希望玩家用一句话如何理解这个游戏？
例如：“一款像素俯视角刷宝肉鸽 ARPG”。

你的回复：一款像素俯视角、暗黑like刷宝、肉鸽


### 1.3 第一版项目说明书主要面向谁？
可选参考：
- 给自己梳理设计
- 给程序开发
- 给美术/动画协作
- 给团队成员理解项目
- 给投资人/外部合作方看

你的回复：主要是给自己梳理设计。也会发给给程序讨论项目基础框架，第一版demo的制作。


## 2. 核心循环

### 2.1 玩家一局内的主要目标是什么？
例如：击败 Boss、尽量探索更多格子、刷指定装备/材料、完成事件目标等。

你的回复：刷指定装备/材料、击败boss（击败boss往往必出高品质装备）。


### 2.2 玩家局外的长期目标是什么？
例如：毕业装备、解锁角色、推进章节、家园养成、宠物收集、时装收集等。

你的回复：毕业装备、解锁角色、推进章节、家园养成、宠物收集、时装收集等，都会拓展。但要分批次有规划完成内容填充，顺序为：装备系统、时装系统、章节，其他为后续版本添加内容。


### 2.3 一局游戏大概多长？
可选参考：
- 5 分钟以内短局
- 10~15 分钟中短局
- 20 分钟以上完整探索

你的回复：20分钟甚至更高，类似于《哈迪斯》的流程长度，40分钟~1.30小时。


### 2.4 一局结束后，玩家获得什么、保留什么、消耗什么？
请描述胜利、失败、主动退出时的差异。

你的回复：胜利，玩家可以从背包挑选多个道具、装备拿回家园，重复使用。失败则降低可挑选道具数量。


## 3. 肉鸽程度

### 3.1 这个游戏的肉鸽随机性主要体现在哪里？
可选参考：地图、事件、装备、技能、词条、怪物、奖励、商店、Boss 等。

你的回复：装备（核心）、技能（由装备（主）、转职、觉醒组合出效果，后期可以在事件中也加入效果增益）、词条、地图、事件、


### 3.2 玩家失败后会损失什么？
可选参考：
- 不损失，所有收益都带出
- 只保留部分收益
- 死亡损失本局大部分收益
- 只损失局内临时 Build，不损失永久养成

你的回复：只损失局内临时 Build，不损失永久养成。降低从关卡获取的收益。如：胜利能拿到30个背包中的道具，失败只能拿到15个背包中的道具。


### 3.3 装备是局内临时装备，还是永久养成装备？
也可以是混合方案：基础装备永久，局内祝福/词条临时。

你的回复：装备是永久，但玩家只能选择部分从关卡中获得的装备或道具（共用背包数量）。


## 4. 战斗体验

### 4.1 战斗节奏更偏哪一种？
可选参考：
- 割草爽感，怪物多、清屏快
- 动作操作，闪避和走位重要
- 弹幕压力，躲避大量投射物
- ARPG 刷图，技能循环和装备强度重要

你的回复：弹幕压力，躲避大量投射物


### 4.2 玩家主要攻击方式是什么？
当前键位有普攻、小技能1、小技能2、大招、闪避、切目标。请补充它们的大致定位。

你的回复：普攻（武器攻击方式，几乎无CD、无能量消耗，高频攻击、伤害低）、小技能1（有一定cd、能量消耗、效果较强）、小技能2（有一定cd、能量消耗、效果较强）、大招（长冷却，技能效果强力，用于对战boss）、闪避（无敌帧与小范围位移、有体力条限制）、切目标（切换技能索敌目标，大部分技能索敌为最近单位）


### 4.3 闪避机制希望如何设计？
例如：无敌帧、位移距离、冷却、体力消耗、可被词条强化等。

你的回复：无敌帧、位移距离、无冷却（但动作演出间隔与延迟）、体力消耗、可被词条强化


### 4.4 切目标机制是否重要？
是自动锁定为主，还是手动切目标为关键操作？

你的回复：自动锁定为主，切目标主要是预防玩家有索敌需求。

## 6. 装备系统

### 6.1 装备部位有哪些？
例如：武器、头盔、衣服、鞋子、项链、戒指、饰品等。

你的回复：①分区1：武器。②分区2：头盔、上衣、腰带、裤子、鞋子。③分区3：戒指、项链、手环。
不同的分区会组合不同套装、有不同的技能、词条获取池。


### 6.2 装备品质从白、绿、蓝、紫、粉、橙、红分别承担什么作用？
当前 demo 中已有大致方向，请补充你希望的定位和稀有度感受。

你的回复：
- 白、绿，垃圾装备，可在局内商店出售获得局内（局内货币不可带出），也可以融合出高品质装备。
- 蓝，垃圾装备，小概率出粉、橙词条，可以通过其他系统提取出该词条镶嵌到毕业装备，也可以融合出高品质装备。
- 紫，前期强力装备，后期乏力。中概率出粉、橙，小概率出红词条，可以通过其他系统提取出该词条镶嵌到毕业装备，也可以融合出高品质装备。
- 粉，前期超强力装备，中期主要装备，后期部分保留。高概率出粉、橙，小概率出红词条，可以通过其他系统提取出该词条镶嵌到毕业装备。（可融合，但收益低）
- 橙，毕业装备，玩家的最终最强。（可融合，但收益非常低）
- 红，特殊毕业装备。获取难度严苛，周期长。需要橙色装备合成。（不可删除、融合）

### 6.3 装备词条有哪些大类？
当前 demo 中提到：属性值、随机二级属性、技能属性、套装、SP 技能。是否还需要其他类型？

你的回复：暂不需要

### 6.5 装备是否需要强化、洗练、分解、出售、收藏等系统？

你的回复：洗练、提取词条/技能、镶嵌词条/技能，分解、出售。收藏为拓展项，优先级低。
