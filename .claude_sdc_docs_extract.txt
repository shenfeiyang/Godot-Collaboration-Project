一：项目概述
SDC 是一款像素风、2D 俯视角、暗黑-like 刷宝肉鸽 ARPG。
项目核心围绕“刷装备、构筑 Build、推进多层关卡、在风险收益中选择撤离或继续挑战”展开。玩家通过长期刷取装备、组合词条与套装、解锁职业与觉醒分支，不断形成新的技能表现和战斗流派。
战斗体验偏弹幕躲避与技能循环，装备长期驱动角色成长与技能裂变。整体参考方向包括 DNF 式刷图掉装、暗黑破坏神式装备流派构筑，以及带有肉鸽风险收益选择的多层探索结构。

二：核心体验目标
本项目希望玩家持续游玩的主要原因，是通过一次次关卡探索获得装备、材料和稀有构筑资源，并将这些资源沉淀为长期角色成长。
刷装备带来的品质反馈：怪物和 Boss 掉落装备，稀有品质和关键词条形成明确追求目标。
Build 构筑带来的成长反馈：装备词条、套装、SP 技能、转职、觉醒共同改变技能表现和战斗方式。
层结算带来的风险收益：每层结束后，玩家需要在“带出收益”与“继续挑战更高奖励”之间选择。
多层推进带来的挑战反馈：越深入关卡，难度越高，奖励越丰富，Boss 掉落和稀有装备追求更强。
永久养成带来的积累反馈：失败只降低本次可带出的收益，不摧毁玩家已经获得的长期成长。
三：基础玩法循环
基础玩法循环是程序理解项目整体骨架的核心。本项目的一轮探索由局外准备、局内推进、层末结算、战利品带出和局外成长组成。
玩家从家园或局外准备界面进入关卡。
进入章节关卡，按照房间节点进行推进。
清理普通战斗、精英战斗、商店、休息区等不同事件类型房间。
获得装备、材料、技能相关道具等战利品。
每进入房间消耗疲劳值，路线选择受到疲劳、奖励和风险影响。
到达当前层末 Boss 房。
击败 Boss 后进入层结算。
玩家选择带出部分战利品返回家园，或继续挑战下一层。继续挑战后，难度提高、奖励更好，但累计战利品继续承担失败风险。
失败时按所在层失败带出数量结算。
带回的装备和资源进入局外长期养成。
该循环的重点不是一次性通关，而是在“刷取—取舍—带出—养成—再挑战”的过程中形成长期追求。
四：关卡与层结构
关卡底层可采用格子或节点配置生成，但玩家实际体验应接近 DNF 式房间推进：清理当前房间后，通过传送门前往下一个节点。
地图底层支持格子或节点配置，具体行列参数可根据体验调整。
玩家在清理房间后，通过 1～3 个传送门选择不同路线。
路线选择可受到事件类型、奖励类型、危险等级和疲劳值影响。
存在迷雾预览机制，玩家可看到下一节点的事件类型、奖励类型、危险等级等信息。
默认一轮探索为 3 层。未来可扩展无尽层、隐藏层、低概率第四层等长期挑战内容。
每层末尾为 Boss 房。
第一阶段房间类型框架可先定义为普通战斗、精英战斗、Boss；商人、休息、深渊等事件作为后续扩展系统保留接口。
五：层结算与带出机制
层结算与带出机制是本项目最重要的风险收益系统之一。玩家每完成一层后，不是简单进入下一层，而是需要判断当前收益是否值得保留，或是否继续挑战更高难度。
每层结束后出现结算选择。
可选行为包括：带出、继续、出售。
带出格子为装备与道具共用格子，玩家需要在装备、材料、技能相关道具之间取舍。
继续挑战后，上一层未带出的战利品继续承担失败风险。
失败不损失永久养成，只降低本轮可带出的收益数量。
家园建筑可提升带出格子数量。

六：战斗框架概述
战斗为 2D 俯视角弹幕压力战斗。玩家需要通过移动、普攻、小技能、大招、闪避和切目标完成战斗。

定位

躲避弹幕、调整站位、寻找输出窗口。
普攻
由武器决定攻击方式，几乎无冷却、低消耗、高频低伤害。
小技能
承担主要战斗循环，有一定冷却和资源消耗，效果强于普攻。
大招
长冷却、高强度，用于关键爆发和 Boss 战。
闪避
具有无敌帧、小位移、体力消耗，可被装备词条强化。
切目标
自动索敌为主，切目标作为辅助功能，解决玩家特定索敌需求。
Boss 战承担操作检验、Build 检验和掉落高潮。具体怪物、Boss 阶段、技能参数、弹幕规则等内容不在本项目说明书展开，后续进入《战斗说明文档》和《怪物与 Boss 设计文档》。
七：装备系统框架概述
装备是本项目第一核心系统。装备承担数值成长、流派构筑、技能裂变和长期刷宝目标。
装备分区
部位

头盔、上衣、腰带、裤子、鞋子
偏生存和基础属性，可形成服饰套装。

偏均衡和特殊构筑，可形成饰品套装。
装备品质分为白、绿、蓝、紫、粉、橙、红。不同品质承担不同的成长阶段和追求价值。低品质装备也需要具备价值，可通过出售、融合、提取稀有词条等方式进入循环。
白、绿：低价值装备，可出售局内货币，也可作为融合材料。
蓝、紫：过渡装备，同时可能产出高价值词条，可用于词条提取或融合。
粉：中前期强力装备，部分可在后期保留。
橙：毕业装备，作为长期追求目标。
红：特殊毕业装备，获取难度高，周期长，作为稀有终局追求。
装备包含品质、基础属性、二级词条、技能词条、套装、SP 技能等结构。词条提取/镶嵌、融合、洗练、分解、出售等系统在本说明书中只做框架占位，详细规则进入《装备系统策划案》。
八：技能与 Build 框架概述
技能系统不只由角色自身决定，而是由角色基础技能、装备、词条、套装、SP 技能、转职、觉醒、技能书等共同影响。装备是技能裂变的主要驱动力之一。
角色基础技能提供初始战斗框架。
武器决定基础攻击方式，并提供特殊技能库。
装备词条可改变技能数值、范围、冷却、弹道、分裂、穿透、追踪等表现。
套装效果可围绕元素、技能类型、召唤物或特定流派进行强化。
SP 技能用于对单个技能进行质变强化，是高品质装备的重要卖点。
转职改变技能池、成长方向和流派方向，玩家在局外选择职业。
觉醒永久解锁觉醒分支，并大幅强化技能体系。
技能形态切换书作为后续系统，用于解锁或切换技能形态。
本项目说明书只概括技能框架，不展开具体技能参数、技能样例和完整技能树。相关内容后续进入《技能系统策划案》和《战斗说明文档》。
九：疲劳值机制概述
疲劳值用于限制探索、制造风险收益、控制单轮时长，并鼓励玩家在路线中做出选择。
每进入一个房间消耗 1 点疲劳值。
疲劳值阈值、增益和减益由配置表控制。
高疲劳可获得正向增益，例如移动速度、攻击等方向的加成。
低疲劳或 0 疲劳可获得减益，用于提高继续探索的压力。
疲劳可通过局内事件、Boss 阶段奖励、疲劳药剂等方式恢复。
疲劳药剂可在局内商店购买，后续也可由家园系统制造。
疲劳值的具体数值、阈值和效果不在项目说明书展开，后续进入配置表和对应系统文档。
十：事件系统框架概述
事件系统用于丰富路线选择、资源补给、风险收益和长期拓展。本项目说明书只定义事件系统存在及扩展方向，不展开单个事件的详细规则。
事件可包含商人、休息、深渊、时装、角色、宠物等。
商人可承担局内购买、出售和补给入口。
休息事件可承担疲劳恢复、生命恢复或战斗准备功能。
深渊事件可作为高风险高收益方向保留，具体形式后续确定。
事件系统需要支持后续扩展和组合。
第一阶段可先保留普通战斗、精英战斗、Boss 作为最小关卡框架。
商人、休息、深渊等具体设计进入后续《事件系统策划案》。
十一：局外养成框架
局外养成用于承接玩家从关卡中带出的装备、材料和解锁资源，使玩家形成长期目标。
家园、角色、宠物、时装、章节推进等均作为长期拓展系统。
当前优先级为：装备系统、时装系统、章节；其他内容后续版本扩展。
家园系统至少承担部分局外成长功能，例如提升带出格子数、制造疲劳药剂等。
角色系统、宠物系统、时装系统的具体玩法后续通过独立系统策划案说明。
本项目说明书只说明局外养成的存在和方向，不展开具体功能细节。
十二：美术与题材方向
美术方向：像素风。
题材方向：奇幻地下城。
氛围方向：偏暗黑地牢。
具体角色、怪物、装备命名和美术表现由后续资源与美术方向决定。
项目整体视觉应服务于刷宝、地下城探索、稀有装备反馈和弹幕战斗可读性。

十四：整体文档定位
《项目说明书》不是完整 GDD，也不是 Demo 开发说明，而是“产品整体框架说明 + 系统边界声明”。
它主要用于让自己和程序理解：
这是一个什么类型的游戏。
项目的核心循环是什么。
哪些系统一定存在。
哪些系统只是框架占位。
哪些内容后续会拆成单独文档。
早期程序架构需要为哪些系统预留接口。
因此，本说明书中出现的装备、技能、事件、疲劳、家园等内容，主要用于确定系统方向和边界。具体数值、功能细节、配置表、单个技能或装备设计，应以后续单系统策划案为准。

装备是第一核心系统，是玩家长期追求、掉落反馈和毕业目标的基础。
装备驱动技能裂变
装备词条、套装、SP 技能会改变技能形态、输出方式和流派体验。
随机地图结构
采用哈迪斯-like 房间推进与三选一路线选择，每局形成不同路线和事件组合。
自选难度 Tag / 关卡词条
玩家进入章节前选择难度 Tag，提高关卡系数分并换取更丰富奖励。
进攻爽感优先
战斗以进攻输出为主要爽点，防御更多作为高难挑战的容错手段。
永久养成保留
失败只影响本局收益，不破坏玩家已获得的永久成长。
旧版“层结算撤离风险收益”已调整，不再使用每层成功/失败带出数量递增的撤退机制。新的风险收益主要由自选难度 Tag、道中传输、全局胜败带出和隐藏 Boss 挑战构成。
3. 核心循环
3.1 局外循环
玩家在家园进行装备整理、职业/技能配置、药剂准备、宠物/时装/家园养成。
玩家选择章节，并在进入章节前选择自选难度 Tag。
难度 Tag 形成关卡系数分，影响本局奖励、事件权重和部分掉落规则。
玩家进入关卡并开始房间推进。
3.2 局内循环
进入房间。
完成战斗、事件或房间目标。
手动拾取装备、材料、局内道具等奖励。
房间完成后出现三选一传送门；特殊传送门可作为额外入口出现。
玩家选择下一个房间，路线不可返回。
推进至当前层 Boss。
3.3 层级循环
击败每层关底 Boss。
触发翻牌奖励。
进入道中商店，可出售、购买装备、材料或局内道具。
获得一次道具对外传输机会，将一定数量道具安全送入局外背包。
继续进入下一层，直到击败最后一层 Boss 或失败。
3.4 胜败循环
击败最后一层 Boss 视为关卡胜利。
击败最后一层 Boss 后，有小概率触发隐藏 Boss；玩家可选择不挑战并按胜利结算。
若挑战隐藏 Boss，则根据挑战结果决定胜利或失败。
任意战斗失败或主动退出，均按失败结算。
胜利和失败的可带出数量为全局数值，不再按层级递增；具体数值受家园、天赋、章节奖励等系统影响。
4. 玩家系统
玩家战斗强调高频移动、持续进攻和 Build 驱动的输出方式。基础操作包括移动、普攻、3 个小技能、1 个觉醒/大招、闪避、切目标、拾取等。
模块
设计方向
普攻
手动按键触发，普攻不算技能，攻击方式随武器切换。是否支持长按连发暂定，后续在战斗说明中确认。
小技能
3 个小技能，由角色本体与职业共同决定，消耗能量并受冷却约束。
觉醒 / 大招
1 个觉醒技能，消耗能量并受冷却约束，由职业觉醒方向决定。

生存属性
存在生命、护盾、受击保护、死亡等机制，大量系统提供生存端属性。
拾取
基础为手动拾取，后续可通过宠物或天赋获得吸附拾取 / 自动拾取体验优化。
5. 战斗系统
战斗核心不是高频防守，而是通过装备和技能构筑获得强输出爽感。防御系统主要用于高难度 Tag、深渊、Boss、精英事件中的容错。
战斗节奏偏边走边打，移动频率高，参考《土豆兄弟》《元气骑士前传》。
进攻优先级高于防守，不同 Build 会改变主要进攻手段权重。
普通怪在装备符合预期时应较轻松，作为清图爽感和掉落来源。
精英怪难度高于普通怪，承担过渡挑战与更高价值奖励。
深渊怪物更难，怪物更多，整体难度可高于普通 Boss。
Boss 是每层关底挑战，承担 Build 检验、操作检验和奖励高潮。
内容
暂定体验目标
普通房
前期 30～90 秒，后期 Build 成型后可 10～30 秒清房。
精英房
暂定普通房 1.5～2 倍时长，最终以体验调试为准。
Boss 房
暂定 2～4 分钟左右，最终以 Boss 机制和数值表为准。
弹幕压力
主要在高难度 Tag、深渊、Boss、精英事件中体现。

8. 装备系统
装备是本项目第一核心系统。装备承担数值成长、流派构筑、技能裂变和长期刷宝目标。具体字段、词条数量、掉落概率和数值以后续装备系统策划案与 Excel 表格为准。
装备分区
部位
定位
武器
武器
决定普攻方式，提供强输出与特殊技能库。
服饰
头盔、上衣、腰带、裤子、鞋子
偏生存、基础属性和服饰套装。
饰品
戒指、项链、手环
偏均衡和特殊构筑，形成饰品套装。
8.1 品质与红装保护
装备品质包含白、绿、蓝、紫、粉、橙、红。
红装非唯一，可删除、可融合，但需要严格保护机制。
红装默认锁定。执行高风险操作时，需要输入装备名称作为确认文字。
8.2 词条与核心养成
词条有品质差异和稀有度差异。
词条可以被提取、洗练、镶嵌、锁定，是游戏核心养成点。
词条提取默认消耗原装备。
保护道具可使词条提取时不消耗原装备，保护道具来源包括高难掉落、Boss、家园制造、商店购买等。
词条锁定用于洗练时保留词条；锁定条目越多，洗练消耗材料越多。
毕业装备打造路径为：装备本体 + 高价值提取词条 + 洗练 / 镶嵌。
8.3 融合、出售与装备去向
融合为局外系统，在特殊建筑处进行。
融合不可指定目标装备，不可保留指定词条，核心用于处理垃圾装备并获得随机成长机会。
垃圾装备优先级：融合 > 出售 > 其他。
出售获得局外货币；局内货币主要用于临时技能增益。
部分技能词条会在专项应用场合拥有强力价值，但当前不在 GDD 中细分词条分类，以技能策划案为准。
9. 关卡、房间与路线选择系统
关卡推进改为《哈迪斯》like 房间推进方式：玩家清完当前房间的怪物、任务或事件后，解锁下一房间传送门。玩家从多个房间选项中选择一个进入，路线不可返回。
模块
规则
章节数量
目标完成 3～5 章节。每个章节美术风格独立，怪物、Boss、装备由配置表控制。
单层房间数
目标约 8～10 个，示例 9～11 个；包含 Boss 房、商店/休息等，具体由配置表控制。
层定位
第 1 层成型，第 2 层强化，第 3 层检验。
三选一传送门
房间完成后展示房间类型、奖励类型、危险等级、事件图标、是否精英/深渊/特殊事件等信息。
特殊传送门
与三选一传送门独立，有概率触发，指向特殊关卡库。
不可返回
地图路线不可返回，该规则绝对成立。
迷雾机制
取消迷雾预览机制。
9.1 特殊传送门
特殊传送门的触发可受随机、事件权重、难度 Tag、章节进度、特定道具等多维度影响。
如果特殊关卡库配置唯一，则指向唯一关卡。
如果特殊关卡库配置多项，则根据权重随机，例如深渊关卡库可随机到火系主题深渊、冰系主题深渊等。
10. 自选难度 Tag 系统
自选难度 Tag 是进入章节前选择的关卡词条系统，是玩家后期挑战与奖励追求的重要来源。该系统替代旧版疲劳值系统承担探索压力、奖励提升和长期挑战目标。
规则项
说明
选择时机
进入章节前选择。
解锁方式
包括但不限于章节进度、通关成就、角色等级等。
选择限制
单局可选择多个 Tag，有数量上限，存在互斥规则；没有分数上限约束。
影响范围
只影响本局。
主要类型
怪物数值类、怪物机制类、玩家限制类为主；地图/事件类、掉落倍率类为辅。
奖励影响
全面影响关卡收益，包括额外掉落池、Boss 保底、翻牌品质、局内商店内容、事件权重等。
示例：小怪攻击 +20%，关卡系数分 +1；小怪移速 +20%，关卡系数分 +3；Boss 生命 +50%，关卡系数分 +5。系数分可带来奖励档位，例如精英怪额外掉落紫色品质以上装备、通关必得觉醒石、深渊事件触发概率提升等。
11. 道中结算、传输与胜败带出系统
新版结算系统由“每层 Boss 奖励 + 翻牌 + 道中商店 + 对外传输 + 全局胜败带出”组成。旧版每层成功/失败带出数量递增机制废弃。
环节
说明
每层关底 Boss
每层关底 Boss 都有配套奖励，使用通用模板。
翻牌奖励
击败 Boss 后从多张牌中选择 1 张，主要产出可带出局外的道具、装备奖励。铜牌、银牌、金牌影响奖励品质并读取不同奖励库。
道中商店
每层 Boss 后固定出现，可出售、购买装备、材料、局内道具。
对外传输
获得一次对外传输道具机会。传出的道具立即进入局外背包，不再受后续失败影响。
传输数量
受家园、天赋、章节奖励、难度分等关联系统影响，具体以配置为准。
胜败带出
失败和胜利的带出数量为全局数值，不再受层级影响；会受关联系统影响。
失败资格
不需要击败 Boss，只判定失败/胜利。
主动退出
道中有退出按钮，玩家随时能失败结算退出关卡；层结算/商店阶段也可主动放弃并按失败带出。
11.1 隐藏 Boss 结算
击败最后一层 Boss 后，有小概率触发隐藏 Boss。
玩家选择不挑战，视为关卡胜利结束。
玩家选择挑战，则根据挑战结果判断结算；挑战失败按失败结算。
12. 事件系统
事件系统用于丰富房间选择、奖励结构、局内强化和长期拓展。事件由关卡表格权重随机，受到章节、层数、难度 Tag、事件权重等影响。
第一批完整设计包含：普通战斗、精英战斗、Boss、商人、休息、深渊、Boss 前准备、NPC、时装、角色。
事件可以组合，例如商人 + 休息、深渊 + 宝箱。
事件会带来各种强力增幅效果，可影响技能、Build 或局内临时强化。
特殊事件地图可额外生成特殊传送门，指向特殊关卡库。

15. 局外养成系统
局外成长用于承接局内带出的装备、材料和角色成长资源。需要控制数值膨胀，GDD 中明确“装备为核心，家园 / 宠物 / 时装为辅助成长”。后续会制作数值模型模拟平衡。
15.1 家园系统
家园核心功能包括提升带出格子、制造药剂、装备加工、角色成长、宠物养成、时装展示、材料生产。
家园存在建筑升级、材料消耗和时间生产。
材料生产包含植物、矿物、稀有矿石等，用于打造增幅药剂、装备、时装等。
家园生产基于真实时间。
15.2 宠物系统
宠物具有多维度功能赋能。
宠物主要提供拾取、属性和辅助效果。
宠物可以提升关卡体验便利性，但不作为主要输出核心。
15.3 时装系统
时装类似 DNF，影响外观，有套装，有属性加成。
时装提供轻量属性，主要提升点为外观、移速、技能裂变收益。
16. 资源、经济与掉落系统
游戏会有丰富的道具和资源设计，使用道具表格控制。绝大部分产出、消耗、掉落概率和保底规则不在 GDD 中写死，以对应系统策划案和配置表为准。
资源包括局内货币、局外金币、强化材料、融合材料、词条材料、洗练材料、疲劳药剂材料、时装材料、宠物材料、章节材料、觉醒/转职材料等。
怪物、精英怪、Boss、事件、分解、出售的产出由表格控制。
装备打造、家园、章节推进、技能、宠物、时装的消耗由表格控制。
Boss 掉落、章节掉落池、品质概率、词条概率、保底规则和稀有掉落提示由表格与专项策划案确定。
17. UI / UX 设计
UI 会有较完整的美术产图，尽可能覆盖多个功能。UI 风格为暗黑、像素、清晰功能型三者结合。
核心 UI 包含主菜单、家园、章节选择、战斗 HUD、房间选择、背包、装备详情、装备对比、层结算/道中结算、死亡结算等。
装备对比、掉落品质提示、稀有掉落反馈需要重点设计。
三选一房间传送门界面需要展示房间类型、奖励类型、危险等级、事件图标、是否精英/深渊/特殊事件等。
关卡页面下方需要展示可选难度 Tag 条目、关卡系数分和对应奖励档位。

美术部分在 GDD 中只写方向，不展开技术规格。详细美术规范与技术文档将在独立讨论中完成。

13. 一阶段风险点
若装备裂变不明显，玩家无法形成刷宝动力。
若房间推进过慢，3 层流程会显得冗长。
若翻牌、商店、传输流程不清晰，玩家难以理解结算价值。
若自选难度 Tag 与奖励反馈脱节，风险收益将不成立。
若 Boss 强度和 Build 成长曲线不匹配，会削弱关卡节奏。
14. 与后续文档的衔接
《一阶段项目开发说明》只负责第一版 Demo 的开发范围和落地顺序。具体战斗公式、技能表、装备表、怪物表、关卡表等内容，仍需要在后续专项策划案中展开。
